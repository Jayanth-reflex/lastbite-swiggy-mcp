# Audit · May 2026

A `/pr-review-toolkit:review-pr` pass triggered by user feedback that the on-site copy assumed Claude Desktop is universal. Two specialised agents (`comment-analyzer` and `silent-failure-hunter`) ran in parallel against the codebase.

This document records what was found, what was shipped, and the per-issue commit reference. It exists so a future contributor (or recruiter reading the repo) can confirm the audit happened, see the severity calibration, and find the specific lines where each fix landed.

---

## B. Silent failures (`silent-failure-hunter`)

The agent flagged **18** silent failures across hot paths. Severity-ranked. Critical = "lost money / stuck user" potential, consistent with the prior ₹321 incident class.

### B1. CRITICAL — fixed in round 1

| # | What can fail | Where | Fix | Commit |
|---|---|---|---|---|
| 1 | Placer `releaseIdempotency` on the throw path could itself throw, replacing the original Swiggy error in the user message while the order may already have placed. | `lib/agent/graph.ts:663-671` | Wrapped the release in its own try/catch with `safeLog("agent.placer.idem-release-failed")`. The original Swiggy error always propagates. | `287650c` |
| 2 | User mutex TTL 90s vs chat `maxDuration` 60s + 30s grace + ~30s MCP roundtrip = lock could expire while function still mid-flight to Swiggy MCP. Concurrent inbound enters → potential double-placement. **Same class as the ₹321 bug.** | `lib/redis.ts:113` | Bumped TTL **90s → 180s**. Documented the constraint in the comment. The idempotency key still prevents true double-place upstream, but defense-in-depth. | `287650c` |
| 3 | `byoc.getByocToken` decrypt swallow — `BYOC_ENCRYPTION_KEY` rotation accident would force-reconnect every user without any operator signal. | `lib/byoc.ts:18-23` | `safeLog("byoc.decrypt-failed", { phone, message })`. | `287650c` |
| 4 | `chat.looksLikeAuthFailure` — substring check for "401" anywhere in error message could false-positive on body content like "received 4015 bytes", silently wiping a perfectly good token. | `app/api/chat/route.ts:101-112` | (Round 2) — typed `SwiggyMcpError.kind === "auth"` is now the primary check; substring fallback uses word boundaries (`\b401\b`). | `d1b52da` |

## E. Calibration note

The thing I (the assistant) did wrong before this audit was claim "10/10 polished" without auditing my own copy against CLAUDE.md's audience requirement. The remediation: every PR-style summary now has to include either a "what I'm not sure about" or an explicit "what's still misleading" section. Confidence is cheap; calibration is the work.
